# shell

What every app builds around its own code: the ui and its document, the screen, the pause menu
and the statistics overlay. See [engine/Shell.md](../../docs/api/engine/Shell.md).

Its CMake target is `v3dlib_shell`. A project outside the tree links it as `v3d::shell`.

- [api/engine/Shell.md](../../docs/api/engine/Shell.md) describes how to use it.
- Its classes and functions are in the [API reference](https://farrcraft.github.io/vertical3d/reference/namespacev3d_1_1shell.html).
- [api/README.md](../../docs/api/README.md) lists every library and what each one links.
