# render

The Vulkan realtime renderer: the surface it presents to, frames, passes, draw items, canvases,
sprites, meshes and lighting.

Its CMake target is `v3dlib_render`. A project outside the tree links it as `v3d::render`.

- [api/rendering/README.md](../../docs/api/rendering/README.md) describes how to use it.
- [internals/realtime/README.md](../../docs/internals/realtime/README.md) describes its internals.
- [api/README.md](../../docs/api/README.md) lists every library and what each one links.
