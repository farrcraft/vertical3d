# animation

Skeletons, poses, animation clips, keyframe curves and the tracks particle effects follow.

Its CMake target is `v3dlib_animation`. A project outside the tree links it as `v3d::animation`.

- [api/Animation.md](../../docs/api/Animation.md) describes how to use it.
- [api/README.md](../../docs/api/README.md) lists every library and what each one links.
