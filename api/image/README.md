# image

Image readers and writers for png, jpeg, tga and bmp, cropping, comparison, the texture atlas
and sprite sheet packing.

Its CMake target is `v3dlib_image`. A project outside the tree links it as `v3d::image`.

- [api/Images.md](../../docs/api/Images.md) describes how to use it.
- [api/README.md](../../docs/api/README.md) lists every library and what each one links.
