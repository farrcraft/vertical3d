# type

Value types and maths: cameras, geometry queries, transforms and random numbers.

Its CMake target is `v3dlib_type`. A project outside the tree links it as `v3d::type`.

- [api/Types.md](../../docs/api/Types.md) describes how to use it.
- [api/Cameras.md](../../docs/api/Cameras.md) describes its cameras.
- [api/README.md](../../docs/api/README.md) lists every library and what each one links.
