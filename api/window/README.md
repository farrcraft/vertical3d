# window

The OS window and its platform calls: size, focus, full screen, text input and the mouse. It
uses no graphics API. See [engine/Window.md](../../docs/api/engine/Window.md).

Its CMake target is `v3dlib_window`. A project outside the tree links it as `v3d::window`.

- [api/engine/Window.md](../../docs/api/engine/Window.md) describes how to use it.
- Its classes and functions are in the [API reference](https://farrcraft.github.io/vertical3d/reference/namespacev3d_1_1window.html).
- [api/README.md](../../docs/api/README.md) lists every library and what each one links.
