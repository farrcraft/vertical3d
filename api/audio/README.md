# audio

Sound playback over SDL3_mixer with a listener and placed voices, the loader for wav files, and
FMOD Studio events when built with FMOD.

Its CMake target is `v3dlib_audio`. A project outside the tree links it as `v3d::audio`.

- [api/engine/Audio.md](../../docs/api/engine/Audio.md) describes how to use it.
- Its classes and functions are in the [API reference](https://farrcraft.github.io/vertical3d/reference/namespacev3d_1_1audio.html).
- [api/README.md](../../docs/api/README.md) lists every library and what each one links.
