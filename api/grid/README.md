# grid

Tile boards: pathfinding, line of sight, terrain from a picture, and overlay geometry.

Its CMake target is `v3dlib_grid`. A project outside the tree links it as `v3d::grid`.

- [api/Grid.md](../../docs/api/Grid.md) describes how to use it.
- [api/README.md](../../docs/api/README.md) lists every library and what each one links.
