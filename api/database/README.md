# database

A connection to a SQLite database, its statements and its transactions. See
[Database.md](../../docs/api/Database.md).

Its CMake target is `v3dlib_database`. A project outside the tree links it as `v3d::database`.

- [api/Database.md](../../docs/api/Database.md) describes how to use it.
- [api/README.md](../../docs/api/README.md) lists every library and what each one links.
