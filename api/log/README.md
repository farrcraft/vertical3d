# log

The process log, a thin wrapper over spdlog.

Its CMake target is `v3dlib_log`. A project outside the tree links it as `v3d::log`.

- [api/engine/README.md](../../docs/api/engine/README.md#logging) describes how to use it.
- Its classes and functions are in the [API reference](https://farrcraft.github.io/vertical3d/reference/namespacev3d_1_1log.html).
- [api/README.md](../../docs/api/README.md) lists every library and what each one links.
