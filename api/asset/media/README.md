# asset_media

The loaders for pictures (png, jpeg, tga, bmp) and glTF models, and sprite sheets.

Its CMake target is `v3dlib_asset_media`. A project outside the tree links it as
`v3d::asset_media`.

- [api/Assets.md](../../../docs/api/Assets.md) describes the loaders.
- [api/Models.md](../../../docs/api/Models.md) describes loading glTF.
- [api/README.md](../../../docs/api/README.md) lists every library and what each one links.
