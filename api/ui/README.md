# ui

The user interface: components, layout, themes, an immediate-mode layer, and the shell every
game shares.

Its CMake target is `v3dlib_ui`. A project outside the tree links it as `v3d::ui`.

- [api/ui/README.md](../../docs/api/ui/README.md) describes how to use it.
- [internals/ui/README.md](../../docs/internals/ui/README.md) describes its internals.
- Its classes and functions are in the [API reference](https://farrcraft.github.io/vertical3d/reference/namespacev3d_1_1ui.html).
- [api/README.md](../../docs/api/README.md) lists every library and what each one links.
