# script

TypeScript run on QuickJS: a runtime that strips a script's types and runs it, with the
functions a host binds into it. See [Scripting.md](../../docs/api/Scripting.md).

Its CMake target is `v3dlib_script`. A project outside the tree links it as `v3d::script`.

- [api/Scripting.md](../../docs/api/Scripting.md) describes how to use it.
- Its classes and functions are in the [API reference](https://farrcraft.github.io/vertical3d/reference/namespacev3d_1_1script.html).
- [api/README.md](../../docs/api/README.md) lists every library and what each one links.
