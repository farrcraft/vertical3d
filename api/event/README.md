# event

Event types, key bindings, and the mapping from a key to a command.

Its CMake target is `v3dlib_event`. A project outside the tree links it as `v3d::event`.

- [api/engine/Input.md](../../docs/api/engine/Input.md) describes events, bindings and commands.
- Its classes and functions are in the [API reference](https://farrcraft.github.io/vertical3d/reference/namespacev3d_1_1event.html).
- [api/README.md](../../docs/api/README.md) lists every library and what each one links.
