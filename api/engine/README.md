# engine

The game engine: the app lifecycle, the main loop, config, input and settings, and the readers
for the window and camera documents. It opens the window.

Its CMake target is `v3dlib_engine`. A project outside the tree links it as `v3d::engine`.

- [api/engine/README.md](../../docs/api/engine/README.md) describes how to use it.
- Its classes and functions are in the [API reference](https://farrcraft.github.io/vertical3d/reference/namespacev3d_1_1engine.html).
- [api/README.md](../../docs/api/README.md) lists every library and what each one links.
