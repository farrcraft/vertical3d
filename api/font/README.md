# font

Rasterizes a typeface with FreeType into a texture atlas and lays out text.

Its CMake target is `v3dlib_font`. A project outside the tree links it as `v3d::font`.

- [api/Fonts.md](../../docs/api/Fonts.md) describes how to use it.
- [api/README.md](../../docs/api/README.md) lists every library and what each one links.
