# version

The tree's version: the numbers of the release it builds toward, and the text a user is shown.

Its CMake target is `v3dlib_version`. A project outside the tree links it as `v3d::version`.

- [api/engine/README.md](../../docs/api/engine/README.md#the-version) describes how to use it.
- Its classes and functions are in the [API reference](https://farrcraft.github.io/vertical3d/reference/namespacev3d_1_1version.html).
- [api/README.md](../../docs/api/README.md) lists every library and what each one links.
