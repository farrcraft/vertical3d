# model

The geometry, materials, skeleton and clips a model file gives.

Its CMake target is `v3dlib_model`. A project outside the tree links it as `v3d::model`.

- [api/Models.md](../../docs/api/Models.md) describes how to use it.
- Its classes and functions are in the [API reference](https://farrcraft.github.io/vertical3d/reference/namespacev3d_1_1model.html).
- [api/README.md](../../docs/api/README.md) lists every library and what each one links.
