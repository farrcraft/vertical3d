# brep

Boundary representation meshes with half-edge topology, which the editor models with.

Its CMake target is `v3dlib_brep`. A project outside the tree links it as `v3d::brep`.

- [editor/Scene.md](../../docs/editor/Scene.md#meshes) describes it, in the editor that uses it.
- [api/README.md](../../docs/api/README.md) lists every library and what each one links.
