# interchange

Scenes read from glTF in no format's terms: nodes, polygon meshes, cameras, lights, curves and
keys. See [Interchange.md](../../docs/api/Interchange.md).

Its CMake target is `v3dlib_interchange`. A project outside the tree links it as
`v3d::interchange`.

- [api/Interchange.md](../../docs/api/Interchange.md) describes how to use it.
- [api/README.md](../../docs/api/README.md) lists every library and what each one links.
