# interchange_usd

The USD reader, which fills the same scene. It is the one library that links OpenUSD.

Its CMake target is `v3dlib_interchange_usd`. A project outside the tree links it as
`v3d::interchange_usd`.

- [api/Interchange.md](../../../docs/api/Interchange.md) describes how to use it.
- Its classes and functions are in the [API reference](https://farrcraft.github.io/vertical3d/reference/namespacev3d_1_1interchange_1_1usd.html).
- [api/README.md](../../../docs/api/README.md) lists every library and what each one links.
