# Odyssey

A tile-based game built on the Vertical3D api: a player in a world of walls and crates, with line
of sight. The world is made of regions, each a board of its own, loaded as the player approaches
them. [docs/Demos.md](../../docs/Demos.md#odyssey) covers how to run it, its controls, its data
files, and which api features it is the reference example for.
