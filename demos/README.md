# Demos

Small games and scenes built on the Vertical3D api, one directory each. Each builds and is tested
with the rest of the tree.

| Demo | What it is |
|---|---|
| [pong](pong/) | Pong against the computer, with sound |
| [tetris](tetris/) | Falling tetrads on a board |
| [voxel](voxel/) | A voxel terrain over Perlin noise, with mouse look |
| [odyssey](odyssey/) | A tile-based world of regions loaded as the player moves |
| [diorama](diorama/) | A lit village of glTF models with shadows and a placed sound |

[docs/Demos.md](../docs/Demos.md) covers how to run each one, its controls, and which api
features it is the reference example for.
