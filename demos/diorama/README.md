# Diorama

A small village of glTF models seen from above, built on the Vertical3D api. It is lit by a sun
that moves around the sky and casts shadows, and a looping sound is placed at its well.
[docs/Demos.md](../../docs/Demos.md#diorama) covers how to run it, its controls, its data files,
and which api features it is the reference example for.
