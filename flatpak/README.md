# flatpak

The Flatpak of every app, which is the Linux release.

- `com.farrcraft.Vertical3D.yml` is the manifest flatpak-builder builds it from.
- `com.farrcraft.Vertical3D.metainfo.xml` is the AppStream description Flathub and software
  centres show.
- The `.desktop` files are the desktop entries of the editor and each demo.

[docs/contributing/Releasing.md](../docs/contributing/Releasing.md#the-flatpak) says how it is
built, checked and published.
