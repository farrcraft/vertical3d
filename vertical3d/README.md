# vertical3d

The Vertical3D editor, a 3D modelling tool. It shows four viewports of one scene over a
construction grid, and it creates and picks meshes, moves them with manipulators, undoes changes,
keys their properties, renders them with moya, and saves projects.

[docs/editor/](../docs/editor/README.md) covers how to run it, how its source is laid out, and how
each part of it works. It models with the mesh library in [api/brep](../api/brep/).
